## 修复设计

| 问题 | 修复与边界 |
| --- | --- |
| G1 在开始检索前猜测回答、耗尽迭代预算 | 明确指定资料范围的计数、日期比较和精确定位问题先执行现有受控搜索工具；不能跳过原生授权或扩展资料集合。 |
| 英文问题被旧重写提示翻译成中文 | 重写提示改为保持原语言；英文输入得到中文重写时回到原问题，规划器不使用被翻译的目标。 |
| 后一个比较来源被排名挤出 | 最多四份明确选定资料允许有界原文读取，通过原 ToolExecutor/AccessGuard，在证据门禁前补齐上下文，工具和读取预算仍有上限。 |
| 日期比较把导出时间当作事件日期 | 优先使用标题、正文记录的会议/报告日期；同文档唯一明确日期传递给其正文块，版本与导出时间字段不被改写。无法证实时仍降级。 |
| 短会议纪要未覆盖后半段限制 | 最多 12 个块且正文不超过 6000 字符的短文档读取完整有界上下文；长文档继续使用邻段窗口。 |
| 正确差值缺少就地引用 | 普通问答复用已验证的来源计算器，从证据解析每项数值，差值同时引用两个操作数来源。无法解析完整数量时不生成确定性表格。 |
| 发现工具误触发来源正文变化 | 精确的当前标题只在 discovery 的 document 元数据记录中允许；match_summary 必须是当前正文/块的真实子串。陈旧摘要、标题、版本/hash、撤权仍拒绝。 |
| 正确事实却指向邻块 | OriginalRead → VerifiedEvidence → ResearchCitation 增加可选 `anchor_excerpt`，保留精确块正文与扩展上下文的区别；精确提交定位必须在 anchor 中找到该事实。旧记录不回填成已核验新 anchor。 |
| 英文证据不足问题被当成不支持操作 | 事实查询保留知识问答意图，检索后解释证据范围；真正的修改/删除等操作仍 unsupported，英文状态提示保持英文。 |
| 补写提示泄漏 | 拒绝包含内部 Question/Original answer/Missing aspects/Missing critical facts/Evidence 标签的补写输出，保留原答案，不把原始提示作为答案发布。 |
| 裁判非法 JSON 类型导致异常 | 评分指令与待评数据分开；校验对象、布尔检查项、整数分值与明确的理由/布尔矛盾。仅非法格式或明确矛盾重试一次，保留原始输出；有效负评分不重试，也不从理由直接翻转布尔值。两次异常仍记未评分。 |
| 不必要的来源访问限制说明 | 已证实提交事实和记录链接时不再自动增加限制章节；明确询问外部可访问性时仍说明该项未由摘录证明。 |
