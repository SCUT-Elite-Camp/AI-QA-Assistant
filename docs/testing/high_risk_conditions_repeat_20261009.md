本轮目的：固定当前版本条件，核对原英文测试集在 Confluence 原生权限边界内的可比性，再对高风险用例做两次重复；不进行全量三遍评测，不修改生产代码或历史分数。

## 原测试集边界核对

18/18 道题的本地冻结 hash 和 metadata version 一致，14/14 份来源通过真实原生 read 检查。进一步读取 Confluence 当前版本发现 CP2 Goals 从冻结 version 17 更新至 version 18：

| 范围 | 结论 |
| --- | --- |
| DR-A-006、DR-A-012、DR-A-018 | 依赖 CP2 Goals，源站版本漂移，暂缓同条件验收 |
| 其余 15 道 | 所需资料本地 hash、冻结版本和源站当前版本一致，可进入当前范围评测 |

不能把本地投影未变化当作源站未变化。后续应重新导入 Goals、更新隔离检索投影，单独审核并冻结新基准；不改历史成绩冒充原冻结验收。

## 重复范围与方法

选择 DR-A-001（跨文档数量对比）、005（日期与后续限制）、013（提交/作者/日期及引用定位）、007（SLA 证据不足）、016（授权范围内缺少 Web 数字证据）。每题 G1、G2 各两次，共 20 个内容坐标。所有选中来源均通过源站版本核对。

G1 使用真实 Chat；G2 使用创建、规划、version/hash 批准、执行、报告及 evaluation trace。保留实际 generation_method，来源驱动确定性表格不计作模型撰写。裁判采用同模型逐项评分，另做助手来源复核；后者也不是独立人类验收。机器误判、未评分和失败单独保留，不能择优覆盖。

这些都是原有、参与过修复或评审的回归题，不声称 unseen holdout。重复稳定性按两次的内容与证据结论判断，不要求文字或引用编号逐字一致。

## 权限与前端边界重复

独立 Web DB 已标记 disposable/isolated；新增已启用非管理员 risk-denied-user，不授予任何文件权限，不复制原生账号绑定。

- 已存在 W30 文档：G2 创建连续两次返回 403，是真实本地 ACL 拒绝，不是题目超范围。
- 与正例相同数量题：G1 连续两次 no_relevant_context、零引用；未返回受保护数字。
- BFF session 原文读取连续两次 HTTP 200，正文 hash 相同。
- 匿名原文读取连续两次 401，缺少 CSRF 的写请求连续两次 403。
- 另一用户读取已有 Research 的报告、事件和原文，三个接口各重复两次，全部返回 404。
- 最初较短 G1 探测被分类为 unsupported、零引用，单独保留为未有效覆盖 ACL 的探测，不冒充权限检查成功。

未修改原站权限、未新增资料正向授权、未运行源站撤权；这轮不能代替完整撤权/版本漂移生命周期矩阵。

### 尚未通过的能力

1. 日期比较：G1 两次均遗漏九月会议证据，错误推断九月早于七月，并输出 `Missing aspects`、`Missing critical facts` 等内部补写提示。G2 两次均降级为需要复核的日期报告，没有完成问题要求的比较。流程完成不等于回答质量通过。
2. 引用覆盖：DR-A-001 的数字和差值均正确，但 G1 第二次差值条目缺少就地引用，证据覆盖不稳定。
3. 引用定位与来源守卫：DR-A-013 的 G1 两次在 find_documents 阶段触发 `source_evidence_changed` 并返回 tool_error，属于安全阻断后的功能失败，不能绕过守卫来使测试通过。G2 第一次提供相邻 chunk_2，第二次才提供直接事实所在的 chunk_1；提交、作者、日期和原站链接均正确，精确定位仍不稳定。
4. 英文证据不足回应：DR-A-016 的 G1 两次返回中文“超出 Agent 能力范围”，没有说明当前授权资料缺少所需证据。G2 两次均正确使用英文说明证据边界，没有替换成 Agent 数字。
5. 裁判可靠性：日期题和引用覆盖出现机器误判通过；DR-A-016 的 G2 第二次评分理由承认回答正确，却将检查项判为失败。DR-A-005 的 G2 第二次裁判输出结构不合法，单独标记未评分。原始评分全部保留，不覆盖为通过。

G2 的 10 份报告均记录为 deterministic；规划与任务阶段使用实际模型，但不能据此声称模型报告综合写作能力已经通过。

请求检索模式统一为 hybrid，实际追踪仅 14/20 个坐标验证为该模式。日期题 G1 两次观察到 bm25 与 hybrid 混合调用；DR-A-013 和 DR-A-016 的四次 G1 因工具失败或未进入检索，没有可验证的检索模式。未观察到标记为 fallback 的回退。此结果不能描述为全部执行使用同一检索路线。

### 性能与权限

G1 成功运行的 6 次请求耗时中位数为 15.65 秒，范围 12.16–30.38 秒。G2 完成运行的 10 次请求中位数为 45.51 秒，范围 30.59–57.09 秒，包含质量未通过的降级报告。此为小样本链路耗时，不是并发容量或全量性能验收；失败耗时未混入成功 G1 的统计。

有效权限/BFF 探测共 16/16 通过：G1 已知 ACL 拒绝 2 次、G2 ACL 拒绝 2 次、BFF 原文/匿名/CSRF 6 次、跨用户隔离 6 次。初始短 G1 问题的两次 unsupported 结果不计入有效权限覆盖。本轮验证实际 BFF session/CSRF 接口，未重复完整浏览器视觉和交互验收。

测试后复核：业务源码指纹、模型、账号绑定配置、BM25、资料文件均未变化，14 份源站文档的版本在本轮期间也未再变化。CP2 Goals 的历史基准版本漂移已在开始前发现并排除相关题目，不能视为已解决。

### 当前版本结论

权限边界的本轮有效探测通过，内容能力仍存在可重复失败。应先处理日期比较、来源守卫的功能失败、英文证据不足回应及引用定位/覆盖，再复测受影响坐标；通过后才进入全量英文评测。版本漂移的三题需重新导入并冻结基准，单独记录与历史结果的不可直接比较性。本轮没有修改业务代码或历史成绩，也没有执行 Git 推送。
