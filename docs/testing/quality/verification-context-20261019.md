## 交付

- 新组件 `agent/agent/evidence/verification_context.py`，消费有效的私有绑定报告与同一批 Evidence。
- 输出逐断言的原文上下文、绑定位置、所选 span、来源身份/版本/hash、构造状态和完整输入 token 数。
- 正文保留标题与连续段落组；表格保留涉及行、表头、列顺序、单位/条件/脚注。
  多行绑定合并；空单元格保守保留整表；代码围栏和 HTML 表格不按普通 Markdown 行拆解。
- 多来源共同保留；任一支持位置/身份失效、缺少 lineage、图片无法表示为文本、表格结构不完整或超预算，
  该断言进入 `needs_review`，不输出部分 premise，不改写断言或截断条件。
- 现有离线入口新增 `--prepare-only`，使用真实来源权限及固定 MiniCheck 分词器导出构造结果，
  **分类器 forward 次数为 0**。原有分类评测输入和历史成绩不改写。

接口及选择边界见[组件契约](../../../agent/docs/verification_context.md)。
它不是授权或语义判定；未来模型调用仍须重新检查当前权限及源版本/hash。
普通历史快照浏览的政策不变，历史可见不等于可以重用于模型证据。
